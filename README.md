## 🚀 How to use

### Clone this repository

```bash
git clone https://github.com/hembramnishant50-glitch/catppuccin-wallpapers.git
cd catppuccin-wallpapers
```

### Set as wallpaper (GNOME)

```bash
gsettings set org.gnome.desktop.background picture-uri "file://$PWD/Category-Landscapes/sunset.jpg"
```

### Set as wallpaper (Hyprland)

```hypr
exec = swaybg -i ~/Pictures/catppuccin-wallpapers/Category-Space/catppuccin-space-01.png -m fill
```

> Tip: Add a random file per folder check to see each category with
> `feh --randomize --bg-fill Category-*` or your WM's built-in picker.

## 🤝 Contributing

Want to add more wallpapers? Pull requests welcome!

1. Fork the repo
2. Place your wallpaper(s) into the matching category folder
3. Name files descriptively (`kebab-case`, matching existing style)
4. Submit a PR

Please only submit wallpapers that are **free to redistribute** and keep files
reasonably sized (prefer compressed JPG/PNG/WebP).
