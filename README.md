## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hembramnishant50-glitch/catppuccin-wallpapers.git
cd catppuccin-wallpapers
```

### 2. Set a wallpaper

<details>
<summary><b>GNOME</b></summary>
<br>

```bash
gsettings set org.gnome.desktop.background picture-uri "file://$PWD/Category-Landscapes/beach.jpg"
gsettings set org.gnome.desktop.background picture-uri-dark "file://$PWD/Category-Landscapes/beach.jpg"
```

</details>

<details>
<summary><b>Hyprland</b></summary>
<br>

```hypr
exec = swaybg -i ~/Pictures/catppuccin-wallpapers/Category-Space/jupiter.png -m fill
```

</details>

<details>
<summary><b>KDE Plasma</b></summary>
<br>

```bash
plasma-apply-wallpaperimage ~/Pictures/catppuccin-wallpapers/Category-Fantasy-Games/hollow-knight.png
```

</details>

<details>
<summary><b>macOS</b></summary>
<br>

```bash
osascript -e 'tell application "System Events" to set picture of every desktop to "'"$PWD"'/Category-Cats/rainbow-cat.png"'
```

</details>

> 💡 **Tip:** Preview a random wallpaper from each category with `feh --randomize --bg-fill Category-*/*` or your window manager's built-in picker.

## 🤝 Contributing

Contributions are very welcome — here's how to add your own wallpapers:

1. **Fork** this repository
2. **Place** your wallpaper(s) into the matching category folder (or propose a new one)
3. **Name** files descriptively, in `kebab-case`, matching the existing style
4. **Submit** a pull request

> Please only submit wallpapers that are **free to redistribute**, and keep files reasonably sized — compressed JPG/PNG/WebP preferred.
